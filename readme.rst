Variable Planetary Infrared Excess
==================================

This is the `rust` implementation of the VPIE method to separate stellar and planetary flux.

Citing
------

If you use this code in your work, please cite `this paper <https://ui.adsabs.harvard.edu/abs/2026arXiv260207127J/abstract>`_ describing the VPIE method as well as the specific version in `zenodo <https://zenodo.org/records/18794395>`_.
